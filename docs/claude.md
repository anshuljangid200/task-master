# AI Guidance - PulseTask

This project was built with AI assistance. To maintain the project, adhere to these rules:

1. **Design System**: 
   - Colors: Primary `#6366f1` (Indigo), Background `#0f172a` (Slate-900).
   - Style: Dark mode by default, glassmorphism for cards.
2. **API Interaction**:
   - Always check `backend/app.py` for endpoint definitions before adding new features.
   - Use Axios for API calls.
3. **Task Logic**:
   - Tasks must have a priority and status.
   - Validation should be done both on frontend and backend.
4. **Prompting Tip**:
   - When asking for UI changes, specify "premium look" and "framer-motion animations".
